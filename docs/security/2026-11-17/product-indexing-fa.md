# فعال‌سازی مجوز ایندکس محصولات

در ۱۷ نوامبر ۲۰۲۶، با تأیید مالک، مجوز ایندکس صفحات تکی محصولات فعال شد. مسیرهای فارسی و انگلیسی محصول هدر index, follow دریافت می‌کنند. تنظیم Nginx در deploy/nginx/oosta-product-indexing.conf قرار دارد و روی سرور نصب شده است.

این مسیرها پاسخ HTML را با private/no-store ارائه می‌کنند و درخواست POST آن‌ها با 503 رد می‌شود. پاسخ درخواست بدون ورود به API سفارش، تیکت و مدیریت برابر 401 است و هدرهای noindex و private/no-store دارد. بررسی هدرهای امنیتی CSP، X-Frame-Options و X-Content-Type-Options روی صفحات عمومی انجام شد.

در بررسی مسیر خزش، فایل robots.txt به آدرس localhost برای Host و Sitemap اشاره می‌کرد. خروجی قبلی هنگام build ساخته شده بود. مسیر robots اکنون در زمان اجرا، دامنهٔ عمومی پیکربندی‌شده را می‌خواند. تست روی خروجی واقعی standalone با دامنهٔ ساختگی زمان اجرا، قبل از اصلاح شکست خورد و پس از اصلاح موفق شد.

دستور npm run verify با ۱۷۳ بررسی اولیه و تست‌های ایزوله موفق بود. ESLint، build محلی، build تصویر production وب و nginx -t موفق بودند. هر دو npm audit تعداد صفر آسیب‌پذیری گزارش کردند. تست هم‌زمانی رویداد بانکی پیام timeout تراکنش را ثبت کرد و مجموعهٔ خود را موفق پایان داد.

بررسی زندهٔ ۲۴ صفحهٔ بازبینی‌شده با User-Agent گوگل انجام شد. پاسخ صفحات، هدر واحد index, follow داشت و آدرس تمام صفحه‌ها در نقشهٔ سایت وجود داشت. فایل robots.txt آدرس https://oostaai.store/sitemap.xml را اعلام می‌کند. این بررسی، مجاز بودن ایندکس را تأیید می‌کند. ثبت واقعی صفحه‌ها در نتایج جست‌وجو به خزش و تصمیم موتور جست‌وجو وابسته است.

از پیکربندی قبلی Nginx در /opt/oostaAI/shared/qa-staging/oostaai-before-product-indexing-20261117.conf نسخهٔ پشتیبان گرفته شد. انتشار وب در /opt/oostaAI/releases/20261117-product-indexing قرار دارد.
