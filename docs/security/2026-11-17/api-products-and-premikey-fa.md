# جداسازی کالاهای API و بازیابی پلن PremiKey

- پلن فعال Plus به همان شناسهٔ کالا در PremiKey وصل بود، اما اثر انگشت ثبت‌شده با متن فعلی فروشنده فرق داشت. پس از بررسی توضیحات همان کالا، اثر انگشت و نگاشت به‌روزرسانی شدند. استثناء ضمانت کامل ۳۰ روزه فقط همان فروشنده، شناسه و اثر انگشت بازبینی‌شده را می‌پذیرد. پلن همچنان تحویل دستی دارد. موجودی بالادست هنگام بررسی ۲۴۲ و قیمت تأمین ۶٫۱۰ دلار بود. اعتبار فعلی خرید آن را پوشش نمی‌دهد.
- ۴۹ پلن بدون سابقهٔ سفارش، استعلام پرداخت یا موجودی به ۷ کالای جدا منتقل شدند. Codex API با ۲۰ پلن به همان دسته اضافه شد. شناسهٔ پلن‌ها، قیمت‌ها، ضمانت و شیوهٔ تحویل حفظ شدند. سهمیهٔ توکن از مدت جدا شد و امضای نگاشت پلن‌های تغییرکرده دوباره محاسبه شد. واردکننده نیز پلن‌های API را قبل از اشتراک‌های معمولی دسته‌بندی می‌کند.
- طرح به‌روزرسانی قبل از اعمال روی کاتالوگ زنده پیش‌نمایش شد. تغییر دیتابیس در یک تراکنش اعمال شد. کپی رمز‌شدهٔ پیش از تغییر خارج از سرور با SHA-256 برابر b3a253914ddc12a55aa8e621f92ea9592237a623c1b6f9d390e5ca9d334c0920 تطبیق داده شد. هیچ خرید، شارژ یا پرداخت آزمایشی انجام نشد.
- رگرسیون تطبیق اثر انگشت ابتدا شکست خورد و پس از تغییر گذشت. تست دسته‌بندی API، اشتراک معمولی و سهمیه/مدت اضافه شد. verify کامل با دیتابیس یک‌بارمصرف، lint فایل‌های تغییرکرده و build API موفق بودند. audit تولید صفر هشدار داشت. audit کامل همچنان ۱۴ هشدار سطح بالا در ابزارهای توسعه گزارش داد.
- API عمومی پلن Plus را در ابتدای گزینه‌ها با ضمانت کامل، موجودی مثبت و بدون نگاشت خصوصی برگرداند. هر هشت صفحهٔ API پاسخ ۲۰۰ دادند و همگی زیر دستهٔ جدید ثبت شدند. درخواست ایجاد سفارش بدون احراز هویت پاسخ ۴۰۱ با no-store گرفت.

## تحویل فوری PremiKey

مالک تحویل فوری همین پلن را تأیید کرد و نگاشت فعال با امضای تنوع تازه به تحویل خودکار تغییر کرد. بررسی خرید استثنای ضمانت را فقط برای همان شناسه و اثر انگشت اعمال می‌کند. سایر هشدارها و تغییر اثر انگشت مانع خرید می‌شوند. آزمون قرارداد، verify کامل، lint و ساخت تصویر API موفق بودند. audit تولید صفر هشدار و audit کامل ۱۴ هشدار ابزارهای توسعه داشت.

در بررسی انتشار، قیمت تأمین ۶٫۱۰ دلار و موجودی کالا ۲۳۹ واحد بود. ماندهٔ کیف پول و سقف مجاز هر دو ۰٫۰۰۹۹۹۹ دلار بودند. هیچ خرید یا شارژی انجام نشد و تحویل واقعی این کالا در این مرحله اجرا نشد.
