# اعلان ثبت‌نام تلگرام

ثبت‌نام موفق یک پیام قالب‌بندی‌شده برای ادمین تعیین‌شده می‌فرستد. عنوان و برچسب‌ها پررنگ‌اند، شناسهٔ کوتاه عضو با قالب کد نمایش داده می‌شود و روش ثبت‌نام و زمان ایجاد حساب به وقت تهران در ردیف‌های جدا آمده‌اند. به درخواست مالک فروشگاه، ایمیل و شمارهٔ موبایل ثبت‌شده در همین پیام خصوصی و با قالب قابل‌کپی نمایش داده می‌شوند. برای اطلاعات ثبت‌نشده پیام «ثبت نشده» نشان داده می‌شود. نام، رمز عبور، توکن و شناسهٔ کامل عضو در پیام قرار نمی‌گیرند.

آزمون دیتابیس ایزوله متن و قالب واقعی پیام، مقصد ادمین، ثبت‌نام با ایمیل، موبایل و هر دو، عدم ارسال رمز و توکن و عدم ارسال اعلان برای ثبت‌نام تکراری یا نامعتبر را با جایگزین مصنوعی Telegram API بررسی می‌کند.

`npm run verify`، ESLint فایل‌های تغییر‌یافته و بیلد API با موفقیت اجرا شدند. `npm audit --omit=dev` و `npm audit` موردی گزارش نکردند.

روی سرور نسخهٔ `oosta-api:20261119-signup-contact` بالا آمد. مسیر سلامت عمومی پاسخ موفق داد و اجرای ربات در لاگ آغاز به کار تأیید شد. ثبت‌نام آزمایشی با Telegram API مصنوعی انجام شد.
