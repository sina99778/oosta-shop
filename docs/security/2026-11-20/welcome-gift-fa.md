# هدیهٔ خرید اول

ثبت‌نام عمومی موفق، حساب و هدیه را در یک عملیات می‌سازد. حساب‌های قدیمی به‌صورت خودکار هدیه دریافت نمی‌کنند. صندوق داشبورد فقط کد همان حساب، درصد و وضعیت هدیه را از مسیر خصوصی `/auth/inbox` می‌خواند. کد در پاسخ ثبت‌نام، اعلان تلگرام، اسناد عمومی و نشانی صفحه قرار نمی‌گیرد.

کد برای اولین خرید پرداخت‌شدهٔ همان حساب ۱۵ درصد از مبلغ فاکتور کم می‌کند. فاکتور برای نمایش است و هنگام پرداخت، کد و مبلغ سمت سرور دوباره بررسی می‌شوند. کدهای تبلیغاتی دیگر همچنان جداگانه اعمال می‌شوند. آغاز سفارش با قفل ردیف حساب انجام می‌شود و ایندکس دیتابیس از دو سفارش هم‌زمان با هدیه جلوگیری می‌کند.

سفارش پرداخت‌شده یا بازپرداخت‌شده اعتبار هدیه را تمام می‌کند. فاکتور کارت‌به‌کارت دارای رسید معتبر یا شاهد بانکی از انقضای خودکار مستثناست. سفارش بدون رسیدِ دارای مهلت، پس از انقضا و مهلت لازم برای ثبت دیرهنگام رسید، می‌تواند بسته شود تا کد دوباره قابل استفاده باشد. نتیجهٔ نامشخص پرداخت آنلاین تا تعیین تکلیف در بررسی باقی می‌ماند.

`npm run verify`، ESLint فایل‌های تغییرکرده و بیلد API و وب پاس شدند. آزمون ایزوله شامل عدم دسترسی بدون نشست، رد کد متعلق به کاربر دیگر، ۱۵ درصد تخفیف، آزادسازی سفارش منقضی، رقابت دو پرداخت و رد استفاده پس از خرید بود. ممیزی وابستگی‌ها همچنان هشدار [GHSA-7589-6fvf-x4pw](https://github.com/advisories/GHSA-7589-6fvf-x4pw) را برای زنجیرهٔ Prisma گزارش می‌کند.

انتشار `20261120-welcome-gift` روی سرور اعمال شد. مسیر صفحهٔ صندوق پیام پاسخ ۲۰۰ داد و مسیر API آن بدون نشست پاسخ ۴۰۱ داد. حساب آزمایشی موقت از مسیر سرویس ثبت‌نام ساخته شد، هدیهٔ فعال ۱۵ درصدی را فقط از پاسخ خصوصی صندوق دریافت کرد و پس از بررسی پاک شد. این بررسی زنده شامل ثبت سفارش، پرداخت یا ارسال اعلان تلگرام نبود.
