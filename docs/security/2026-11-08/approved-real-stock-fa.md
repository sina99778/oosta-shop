# خرید واقعی با مجوز صریح موجودی کیف پول

کاربر پس از توضیح نبود قفل قیمت در API، سقف کل را از یک دلار به **۱٫۵۸ دلار شامل ۰٫۰۱ دلار تست قبلی** افزایش داد و یک خرید واقعی را تأیید کرد. هدف iLovePDF Premium یک‌ساله، SKU54، قیمت استعلامی ۰٫۴۰ دلار است؛ ریسک تغییر قیمت تا موجودی تأییدشدهٔ ۱٫۵۷ دلار پذیرفته شد. این مجوز فقط همین آزمون است و فروش عمومی را فعال نمی‌کند. محدودیت گزارش قبلی با این تأیید صریح جایگزین شده، نه با ادعای وجود قفل قیمت.

## پیاده‌سازی و بررسی

فقط انتخاب خصوصی exact SKU/name/type/maxCost=.4 با `walletExposureUsd=1.57` از توقف stock مستثناست. فیلد در snapshot تلاش ذخیره می‌شود و body HTTP هنوز تنها requestKey دارد. استعلام قیمت و خواندن مجدد GET کیف پول بلافاصله پیش از POST، موجودی finite/کافی/حداکثر۱٫۵۷ را می‌سنجند. هزینهٔ مورد انتظار حداکثر۰٫۴۰ است؛ authorization باید کل ریسک۱٫۵۷ را پوشش دهد. قبل از شبکه، زیر قفل مشترک مجموع رزرو همهٔ مجوزها حداکثر۱٫۵۸ کنترل می‌شود. مبلغ نامعلوم stock کل۱٫۵۷ را رزرو می‌کند؛ SENDING/UNCERTAIN/REVIEW خرید جدید با هر UUID را مسدود می‌کنند. یک پاسخ با مبلغ متفاوت به‌صورت موفق تحویل داده نمی‌شود.

ردشدن اثبات‌شدهٔ بررسی کیف پول قبل از POST، FAILED_NO_CHARGE ثبت می‌شود؛ خطای نامعلوم پس از شروع POST همچنان UNCERTAIN است. این ایراد با تست HTTP ایزوله ابتدا به‌صورت UNCERTAIN به جای FAILED_NO_CHARGE بازتولید شد و پس از اصلاح پاس شد. تست جداگانه پاسخ برداشت۰٫۹۰ در برابر انتظار۰٫۴۰ را مبهم نگه می‌دارد، vault نمی‌سازد، کل۱٫۵۷ را رزرو می‌کند و خرج مجوز بعدی را رد می‌کند.

قرارداد انتخاب تأییدشده ابتدا با ZodError فیلد ناشناخته شکست خورد. پس از پیاده‌سازی، حالت مجاز، نبود مجوز، موجودی NaN/Infinity/بالاتر از سقف، تحویل و replay، مالک/غیرمالک، تغییر انتخاب جاری و مرز بودجه در دیتابیس disposable پاس شدند. پاکسازی fixtureهای QA فقط در همین دیتابیس یک‌بارمصرف و پشت ISOLATED_REGRESSION_DB انجام شده است. دیتابیس کاری reset/seed نشد.

`npm run verify`، lint کل پروژه و production build API/وب با exit0 پاس شدند. هر دو audit کامل و production صفر یافته گزارش کردند؛ JSONهای approved-stock-audit در این پوشه‌اند. بازبین مستقل دو کمبود فوق را گزارش کرد و پس از رفع و تست، یافتهٔ قابل اقدام دیگری در محدودهٔ تغییر نداشت. وابستگی یا migration جدید اضافه نشد. ظاهر سرمه‌ای/نعنایی و دسترسی‌های خصوصی حفظ شدند.

## محدودیت

API تأمین‌کننده همچنان سقف برداشت یا قیمت قفل‌شده ندارد؛ بررسی کیف پول جای آن را نمی‌گیرد. این اجرای محدود بر پذیرش صریح ریسک موجودی، عدم شارژ هم‌زمان کیف پول و نبود اعتبار/برداشت اضافهٔ بالادست متکی است. این الگو مجوزی برای فروش خودکار عمومی نیست. خرید یک اکانت و مشاهدهٔ وضعیت آن، ضمانت یک‌سالهٔ فروشنده یا نبود باگ کل سامانه را اثبات نمی‌کند.


## نتیجهٔ واقعی

نسخهٔ `/opt/oostaAI/releases/20261108-approved-stock` پس از backup و build سرور فعال شد. فقط API و وب Oosta بازسازی شدند؛ schema تغییری نداشت. بررسی عمومی پیش از خرید، نقش/مالکیت/عدم cache و مجوز مالی غیرفعال را تأیید کرد. شمار مصرف ارز از ۲ به ۳ رسیده بود؛ دفتر حفظ شده و reset نشده است.

فقط **یک POST خرید** از مسیر مدیر سایت برای SKU54 فرستاده شد. سفارش بالادست `116970` و سفارش سایت `cmw7s04ib0006qt019p9z8sst` با وضعیت DELIVERED و هزینهٔ **۰٫۴۰ دلار** ثبت شدند. اولین بررسی کیف پول هنوز مقدار قبل را برمی‌گرداند؛ اسکریپت به‌جای تکرار خرید متوقف شد. بازخوانی بعدی موجودی۱٫۱۷ را تأیید کرد: ۱٫۵۷ منهای۰٫۴۰. بررسی ادامه فقط سفارش موجود را خواند/reconcile کرد؛ خرید جدیدی نفرستاد.

هزینهٔ تجمعی واقعی **۰٫۴۱ دلار** با احتساب تست API قبلی است. دو تلاش کل، برای سفارش جدید یک واحد inventory، صاحب سفارش HTTP200/no-store و غیرصاحب HTTP404 تأیید شدند. مبلغ پرداختی مشتری صفر و منبع تأمین هزینه کیف پول اپراتور است. reconciliation تکراری همان سفارش/یک واحد را حفظ کرد و موجودی کیف پول تغییر نکرد. مجوز مالی در finally غیرفعال شد و در بررسی بعد نیز false بود. خروجی raw تحویل و audit مالی فقط در پوشهٔ خصوصی خارج از Git و فایل‌های mode600 سرور نگهداری می‌شوند؛ رمز و توکن چاپ نشده‌اند.

**مغایرت مدت/نوع دوره:** عنوان فروشنده «Premium 1Yr» است، اما تا تاریخ رسمی پایان از ۸ نوامبر۲۰۲۶ حدود **۳۳۱ روز** باقی است؛ ۱۲ ماه کامل از زمان این خرید نیست و صفحه آن را Trial می‌نامد. بنابراین ورود و فعال‌بودن فعلی پاس شدند، ولی وعدهٔ مدت کامل یک‌سال تأیید نشد. این موضوع برای ارزیابی کیفیت تأمین‌کننده ثبت شد؛ refund، پیام به فروشنده یا خرید جایگزین خودکار انجام نشد.
