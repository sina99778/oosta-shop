# فعال‌سازی ایندکس صفحات قوانین فارسی

- مسیرهای فارسی شرایط خرید، ضمانت و بازگشت وجه، و حریم خصوصی به فهرست مجاز Nginx و Sitemap اضافه شدند. سایت محتوا را از متن پیش‌فرض فعلی می‌خواند و در صورت انتشار همان اسلاگ در CMS فقط یک نشانی در Sitemap خواهد بود.
- تست‌های رگرسیون ابتدا نبود صفحات در Sitemap و فهرست مجاز را بازتولید کردند. `npm run verify`، `npm run lint`، بیلد تولید وب محلی و Docker، و `nginx -t` پاس شدند. هر دو `npm audit` صفر مورد گزارش کردند.
- وب با نسخهٔ `20261122-policy-indexing` از کامیت `c7bbd92` منتشر شد و Nginx پس از بررسی پیکربندی reload شد. هدر هر سه صفحهٔ فارسی در پاسخ عمومی `index, follow` است و هر صفحه canonical خودش را دارد. سه مسیر انگلیسی، صفحات خصوصی و API سفارش همچنان `noindex` دارند. API سفارش برای مراجعهٔ بدون ورود `401` با `no-store` پاسخ داد.
- Sitemap عمومی ۱۲۲ نشانی یکتا دارد. ثبت واقعی صفحه‌ها در نتایج گوگل در این نوبت بررسی نشد. کانتینرهای API و PostgreSQL جابه‌جا نشدند. سلامت اتصال دیتابیس و دسترسی Sitemap پس از آزادسازی کش همان بیلد دوباره تأیید شد و ۲٫۱ گیگابایت فضای آزاد باقی ماند.
