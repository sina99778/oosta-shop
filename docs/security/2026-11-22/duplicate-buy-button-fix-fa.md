# رفع باگ تکرار دکمهٔ «افزودن به سبد خرید» هنگام تغییر پلن

در صفحهٔ محصول (`apps/web/components/product-detail-view.tsx`) دو فرزند هم‌سطح داخل کارت خرید (`<Card>`):
- `<ProductPurchaseAction key={plan?.id} ...>`
- `<details key={plan.id} ...>` («شرایط اشتراک انتخاب‌شده»)

از یک مقدار یکسان (`plan.id`) برای `key` استفاده می‌کردند. در الگوریتم آشتی React، کلیدهای فرزندان یک آرایه باید بین هم‌سطح‌ها یکتا باشند؛ تداخل این دو کلید باعث می‌شد هنگام تغییر وضعیت احراز هویت پس از هیدریشن (`authLoading`) و در هر بار تغییر پلن، React نمونهٔ قبلی `<ProductPurchaseAction>` (شامل دکمهٔ خرید و نوار موبایل) را از DOM حذف نکند و دکمه‌های «افزودن به سبد خرید» روی هم انباشته شوند.

### اصلاح انجام‌شده
- کلید همهٔ فرزندان هم‌سطح کلیددار داخل کارت خرید در `apps/web/components/product-detail-view.tsx` پیشوند مجزا گرفتند:
  - `StockAlertButton`: ``alert:${plan.id}:${token ?? ""}``
  - `SupplierQuotePanel`: ``quote:${plan.id}:${JSON.stringify(plan.variant)}:${token ?? "anonymous"}``
  - `ProductPurchaseAction`: ``buy:${plan?.id ?? ""}``
  - `<details>` شرایط اشتراک: ``terms:${plan.id}``
- در `scripts/variant-ui-contracts.cjs` تابع `assertUniqueSiblingKeys` اضافه شد که ابتدا خطای تداخل کلید `"fixture-auto"` را بازتولید کرد و پس از اصلاح، یکتایی کلیدهای هم‌سطح را در حالت‌های موجودی فروشگاه، موجودی تأمین‌کننده، `OUT_OF_STOCK` و `ON_REQUEST` بررسی می‌کند.

### بررسی‌ها و محدودیت‌های باقیمانده
- `npm run verify`، `npm run lint` و `npm run build` برای هر دو سرویس API و وب پس از آخرین ویرایش کد با موفقیت کامل اجرا شدند (فقط تغییر وب؛ بدون نیاز به تغییر API یا مهاجرت دیتابیس).
- نسخهٔ وب `20261122-duplicate-buy-button-fix` منتشر شد. در Edge روی صفحهٔ زندهٔ ChatGPT، پیش از انتشار دو دکمه پس از هیدریشن مشاهده شد. پس از انتشار در عرض‌های ۱۳۶۶ و ۳۹۰ پیکسل، دکمهٔ اصلی پس از چند دور تغییر پلن یکتا ماند. در موبایل فقط هنگام عبور از دکمهٔ اصلی، یک دکمه در نوار ثابت ظاهر شد و با برگشت به بالا حذف شد. در این آزمون سفارشی ایجاد نشد.
- از اجرای مجدد `npm run verify`، ESLint، بیلد تولید وب و هر دو npm audit خروجی موفق گرفتیم. پس از پاک‌سازی کش موقت بیلد، ۲٫۴ گیگابایت فضای آزاد باقی ماند. API و ایمیج بازگشت وب حفظ شدند.
