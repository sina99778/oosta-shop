# مرحلهٔ سوم (بخش ۲): خلاصهٔ ضمانت، تحویل و پشتیبانی کنار دکمهٔ خرید

در صفحهٔ محصول (`apps/web/components/product-detail-view.tsx` و `apps/web/lib/product-variant.ts`) کنار دکمهٔ خرید، خلاصهٔ ساختاریافتهٔ چهاربخشی (`planTrustSummary`) برای همان پلن انتخاب‌شده اضافه شد:

- **ضمانت** — مدت و نوع پوشش واقعی همان پلن (`پوشش کامل`، `فقط مشکل ورود`، `بدون ضمانت` یا `ضمانت مشخص نشده` برای پلن‌های بدون مشخصات ساختاری) همراه با لینک مستقیم به `/fa/p/return-policy` (یا `/en/p/return-policy`). هیچ پوششی برای پلن‌های بدون داده ساخته نمی‌شود.
- **روش تحویل** — نوع دریافت (`اکانت آماده`، `اینوایتی`، `کد فعال‌سازی`، `فعال‌سازی روی حساب`) و شیوهٔ تحویل (`تحویل خودکار` یا `تحویل دستی`). در صورت فعال بودن روش کارت‌به‌کارت، عبارت `(کارت‌به‌کارت پس از تأیید رسید)` اضافه می‌شود تا تحویل آنی پیش از تأیید رسید القا نشود و متن تکراری زیر دکمهٔ خرید حذف شد.
- **دسترسی و مدت** — نوع دسترسی (`اختصاصی`، `اشتراکی`، `تیمی`)، مدت اشتراک و در صورت تعریف بودن، منطقه و سهمیه.
- **پشتیبانی بدون نیاز به ورود** — لینک مستقیم به صفحهٔ عمومی تماس (`/fa/p/contact` یا `/en/p/contact`) برای مشاهدهٔ راه‌های ارتباطی و راهنمای پیگیری سفارش، در کنار لینک تلگرام پیش از خرید (`supportHref` در صورت تنظیم بودن). با حفظ قاعدهٔ `scripts/variant-ui-contracts.cjs`، لینک صفحهٔ احراز هویت‌شدهٔ `/support` به صفحهٔ عمومی محصول اضافه نشد تا کاربر مهمان به صفحهٔ ورود هدایت نشود.

در `scripts/variant-ui-contracts.cjs` تست‌های واحد `planTrustSummary` (پوشش کامل، مشکل ورود، بدون ضمانت، دادهٔ ناقص و حالت کارت‌به‌کارت) و رندر `<dl>` خلاصهٔ اعتماد همراه با لینک‌های `/fa/p/return-policy`، `/fa/p/contact` و `supportHref` اضافه شدند. `npm run verify`، `npm run lint` و `npm run build` برای هر دو سرویس API و وب پس از آخرین ویرایش کد با موفقیت کامل اجرا شدند (بدون تغییر در API، دیتابیس یا نیاز به مهاجرت).

نسخهٔ وب `20261122-product-trust-summary-phase3` منتشر شد. پاسخ ۲۰۰، خلاصه و پیوندهای ضمانت، تماس و تلگرام در صفحهٔ ChatGPT فارسی و انگلیسی از مبدأ و دامنهٔ عمومی تأیید شدند. در Edge، چیدمان صفحهٔ فارسی در عرض‌های ۳۹۰ و ۱۳۶۶ پیکسل به‌صورت بصری و با آزمون عرض کنترل شد. هر چهار ردیف و پیوندها بدون سرریز دیده شدند.

کانتینر API تعویض نشد و اتصال پایگاه داده سالم بود. پس از پاک‌سازی کش موقت بیلد، ۲٫۷ گیگابایت فضای آزاد باقی ماند و تصویر وب نسخهٔ قبلی برای بازگشت موجود بود. بررسی زنده در محدودهٔ نمایش محصول و پیوندها انجام شد و سفارش یا پرداخت ثبت نشد.
