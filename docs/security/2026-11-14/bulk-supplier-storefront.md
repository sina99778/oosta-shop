# Bulk supplier storefront catalog

Read fresh catalog snapshots for ToolsMarket, AItoolify, both distinct Canboso accounts and VenteBot. At import time they contained 750 offers, including 493 with reported stock or on-request availability. The checked import classified 405 eligible offers and added 401 plan records after retaining existing mappings. There were 88 available offers held for manual review, including excluded Gemini editions, account/OTP products, ambiguous descriptions and warranty conflicts. Zero-stock rows were not bulk-published. The private server-side JSON report records each held offer and reason.

Published service-level pages across eight categories with a separate plan for each imported supplier offer. The reviewed ChatGPT full warranty and Gemini Pro-only scope were preserved. Unverified delivery displays as manual. Stock and quote computation still use the approved fingerprint-based mapping and the existing live catalog freshness window. Public checkout remains closed. No orders were placed and no supplier balances were debited. Network service titles omit the VPN acronym, while their descriptions identify the service accurately and explain that ping depends on the route, ISP and game server.

Each page uses a titled WebP cover composed from one of eight generated category artworks. Existing image overrides are preserved. The actual staged import used `scripts/import-supplier-storefront.cjs` and `scripts/supplier-storefront-families.json`, with its covers archived on the storefront host. Both database archives were inspected with pg_restore listing. The web release is `20261114-bulk-catalog`.

Full verify, lint, web build, Docker web build and both npm audits passed. Preview HTTP smoke passed. A rapid public sweep hit the configured HTTP rate limit. The follow-up reads the actual catalog handler and image service inside the deployed container for every page and checks representative public pages separately. Future additions need another reviewed import. Existing mapped stock counts refresh through the background supplier sync.
