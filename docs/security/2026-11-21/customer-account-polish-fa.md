# بازطراحی ورود و حساب مشتری

صفحات ورود، ثبت‌نام و بازیابی رمز از قاب مشترک اوستا استفاده می‌کنند. لینک بازیابی کنار برچسب گذرواژه است. نشانگر قدرت رمز پس از ورود اولین کاراکتر ظاهر می‌شود. تغییر نوع نمایشی هر فیلد مستقل است.

مرحلهٔ دوم ثبت‌نام روی کد ایمیل تمرکز می‌کند. ارسال مجدد پشت یک بخش بازشونده قرار دارد و پس از درخواست موفق، تمرکز به فیلد کد برمی‌گردد. درخواست مجدد همچنان به رمز فعلی و قواعد محدودیت درخواست سرور وابسته است. اعتبارسنجی رمز، کد و توکن بازیابی، چرخش نشست و ثبت هدیه طبق قواعد موجود API انجام می‌شود.

در حساب مشتری، نمایه و وضعیت ایمیل کنار خلاصهٔ سفارش‌ها و وضعیت هدیه دیده می‌شوند. ردیف سفارش حداکثر نام اولین محصول را نشان می‌دهد و شماره و تعداد اقلام را نگه می‌دارد. وضعیت کوپن از صندوق پیام حساب خوانده می‌شود و خود کد فقط در صفحهٔ صندوق پیام نمایش داده می‌شود. فرم تغییر رمز و بخش خروج از دستگاه‌ها پیام‌های مربوط به خودشان را نمایش می‌دهند.

## دامنهٔ API و امنیت

`GET /orders` همچنان به کاربر احرازشده محدود است و فیلتر مالک از همان شناسه استفاده می‌کند. فیلد افزوده فقط نام محصول را از یک قلم می‌خواند. اطلاعات تحویل، کلید، رمز و رسید در پاسخ فهرست قرار نمی‌گیرند. بررسی داده و cache با درخواست مالک، کاربر دیگر و درخواست ناشناس روی پایگاه دادهٔ یک‌بارمصرف انجام شد. فرانت قدیمی می‌تواند فیلد جدید را نادیده بگیرد و فرانت جدید برای پاسخ نسخهٔ قبلی به شمارهٔ سفارش برمی‌گردد.

## بررسی‌ها

- آزمون مرورگر با دادهٔ ساختگی، فرم موبایل، رمزسنج، نمایش رمز، تمرکز فیلد کد، ارسال مجدد، انتقال به داشبورد، نام محصول، وضعیت ایمیل، کوپن و تغییر رمز از لینک موقت را پوشش می‌دهد.
- عملیات مربوط به بازیابی و ارسال مجدد در آزمون‌ها stub شده‌اند. مسیر دریافت واقعی نامه در صندوق Gmail در دامنهٔ این بررسی نبود.
- `npm run verify` با ۱۸۲ بررسی پایه و آزمون‌های جداگانهٔ پایگاه داده، ESLint فایل‌های تغییرکرده، بیلد production و شش سناریوی مرورگر موفق بودند. هر دو بررسی وابستگی npm صفر مورد گزارش کردند.
- نسخهٔ `20261121-customer-account-polish` برای وب و API منتشر شد. بررسی زنده وضعیت مسیرهای ورود و بازیابی در دو زبان، فایل‌های وب، سلامت پایگاه داده، هدرهای بازیابی و پاسخ ۴۰۱ بدون کش برای سفارش، صندوق پیام و تیکت را تأیید کرد.
