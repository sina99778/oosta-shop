# سبد مهمان و مسیر خرید موبایل

سبد مهمان فقط شناسهٔ پلن و زمان افزودن را در مرورگر نگه می‌دارد. سقف ۱۰ قلم است و هر قلم پس از ۲۴ ساعت دیگر در سبد خوانده نمی‌شود. ذخیرهٔ مهمان موجودی را رزرو نمی‌کند. قیمت و موجودی از `GET /cart/guest-preview` می‌آید و این مسیر بدون محاسبهٔ فاکتور، فقط پلن‌های عمومی فعال را نشان می‌دهد. پاسخ `private, no-store` است و ورودی حداکثر ۱۰ شناسهٔ یکتا می‌پذیرد. قیمت تقریبی از همان دادهٔ ذخیره‌شدهٔ کاتالوگ و نرخ معتبر می‌آید.

پس از ورود مشتری، اقلام با همان `POST /cart/items` منتقل می‌شوند. شناسهٔ حساب مورد انتظار با هویت نشست سرور مقایسه می‌شود تا درخواست معوق در حساب دیگری اجرا نشود. بررسی نقش از پایگاه داده و قفل تراکنش سبد حفظ شده است. اقلام پذیرفته‌شده، تکراری یا ناموجودِ تأییدشده پاک می‌شوند. هنگام پر بودن سبد یا خطای موقت، قلم‌های منتقل‌نشده با دکمهٔ تلاش دوباره باقی می‌مانند. ادمین انتقال خودکار ندارد و بازبینی فاکتور همچنان به نشست احراز هویت‌شده و مالکیت قلم نیاز دارد.

نوار خرید موبایل پس از عبور از دکمهٔ اصلی ظاهر می‌شود. دکمهٔ خرید یا اعلان موجودی در هر دو جایگاه از همان وضعیت و عملیات استفاده می‌کند. مسیرهای «درباره ما» و «تماس» در فارسی و انگلیسی به مسیر اصلی خود هدایت می‌شوند. صفحهٔ منتشرشدهٔ CMS اولویت دارد و لینک‌های تماس از تنظیمات سایت خوانده و اعتبارسنجی می‌شوند.

تست‌های رگرسیون، سقف و انقضای سبد، فیلتر پلن غیرفعال، اعتبارسنجی شناسه‌ها، تغییر نشست، انتقال ناقص، نمایش نوار و ریدایرکت‌ها را پوشش می‌دهند. آزمون پرداخت از منابع ساختگی و دیتابیس موقت استفاده می‌کند.

`npm run verify`، ESLint و بیلد تولید API و وب موفق بودند. هر دو بررسی npm audit صفر مورد گزارش کردند. در Edge با نمای موبایل ۳۹۰ پیکسلی و API ساختگی، افزودن از نوار خرید، شمارندهٔ مهمان، برگشت از ورود به سبد، انتقال با نشست مشتری، حفظ قلم در حالت سبد پر، تلاش دوباره و تغییر سبد از تب دیگر بررسی شد.

نسخهٔ `20261122-storefront-purchase-phase2` منتشر شد. سلامت API و پاسخ پیش‌نمایش سبد پیش از تعویض وب تأیید شدند. روی دامنهٔ عمومی، پاسخ پیش‌نمایش و هدر کش، رد ورودی تکراری، رد دسترسی مهمان به سبد حساب و سفارش‌ها، بازشدن سبد عمومی و ریدایرکت‌های ۳۰۸ هر دو زبان بررسی شدند. «درباره ما» و «تماس» همچنان هدر `noindex` دارند. کارت‌به‌کارت فعال و درگاه آنلاین غیرفعال بود. انتقال در مرورگر با دادهٔ ساختگی و بررسی نسخهٔ زنده فقط با درخواست خواندنی انجام شد. بعد از جمع‌آوری کش موقت همین بیلد، ۱٫۸ گیگابایت فضا آزاد بود.
