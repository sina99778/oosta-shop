# ثبت و مدیریت نظر مشتری

- درخواست ثبت نظر به حساب مشتری، محصول فعال و سفارش پرداخت‌شدهٔ همان مشتری برای همان محصول محدود شد. نظر تا تأیید ادمین در وضعیت بررسی باقی می‌ماند. فرانت‌اند برای مشتری بدون خرید قبلی پیام مشخص نمایش می‌دهد.
- مسیرهای ثبت و مدیریت نظر با تطبیق محدود URL و الزام HTTPS از Nginx عبور می‌کنند. Backend نقش جاری و CSRF درخواست‌های کوکی را بررسی می‌کند. پاسخ ثبت نظر و پاسخ‌های ادمین private و no-store هستند.
- آزمون قبل از اصلاح ثبت نظر حساب بدون خرید را با پاسخ ۲۰۱ بازتولید کرد. مجموعهٔ آزمون از سفارش و پرداخت ساختگی برای پوشش درخواست بدون ورود، حساب بدون خرید، سفارش پرداخت‌نشده، خرید موفق و مجوز تأیید ادمین استفاده می‌کند.
- وضعیت بیرونی سایت، API و TLS بررسی شد. ژورنال آخرین بکاپ زمان‌بندی‌شدهٔ ۲۱ نوامبر را با شناسهٔ تلگرام `247` و یک بخش موفق ثبت کرده است. بازکردن فایل همان پیام در تلگرام بررسی نشد.
- نسخهٔ `20261121-customer-reviews` پس از موفقیت `npm run verify`، ESLint، ساخت دو تصویر تولید و هر دو npm audit منتشر شد. روی دامنه، درخواست ناشناس ثبت نظر با ۴۰۱ و no-store رد شد. روش نامجاز و تأیید نظر بدون ورود نیز رد شدند. سلامت دیتابیس و پیکربندی پرداخت بررسی شد. زرین‌پال، دامنهٔ ایندکس و مونیتورینگ خارجی تغییر نکردند.
