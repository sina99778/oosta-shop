# بهبود سئو و محتوای فروشگاه

نسخهٔ وب `20261121-seo-editorial` با API موجود `20261121-account-hub` منتشر شد. مسیر قدیمی DeepSeek که صفر پلن داشت در هر دو زبان به صفحهٔ DeepSeek API با کد ۳۰۸ می‌رود و از نقشهٔ سایت حذف شده است. تأمین‌کننده، موجودی، تنظیمات پرداخت، مسیرهای خصوصی و قواعد Nginx در این انتشار تغییر نکردند.

رکورد قدیمی DeepSeek از کاتالوگ عمومی خارج شد. عملیات پس از بررسی نقش جاری مدیر، فعال بودن مقصد با پلن قابل نمایش و خالی بودن رکورد قدیمی از پلن، موجودی و سفارش انجام شد. وضعیت قبلی رکورد در `deepseek-before.json` در کنار فایل‌های بازگشت ذخیره شد.

بین ده مقاله و صفحات مرتبط فروشگاه لینک دوطرفه قرار گرفت. لینک‌های اشتراک و اعتبار API برای Claude، Cursor، Grok و Freepik بر اساس صفحهٔ منتشرشدهٔ مقصد نمایش داده می‌شوند. مقالهٔ ابزارهای کدنویسی به Microsoft Copilot وصل نشده چون موضوع آن GitHub Copilot است. مقصدهای منتشرنشده یا خطادار در بخش مرتبط نمایش داده نمی‌شوند. پیوند تلگرام برای پلن ناموجود از تنظیمات موجود پشتیبانی می‌آید.

صفحات فهرست محصولات و مجله دادهٔ ساختاریافتهٔ CollectionPage و BreadcrumbList دارند. صفحات قوانین تصویر اشتراک‌گذاری و توضیح یک‌خطی با برش در مرز کلمه دارند. الگوی عنوان مدیریت پسوند نام برند را در بازهٔ پیشنهادی محاسبه می‌کند. مرز ۵۰ کاراکتر برای عنوان بدون پسوند، قاعدهٔ داخلی پیش‌نمایش است. گوگل طول قابل نمایش را بر اساس عرض نتیجه تعیین می‌کند. [راهنمای عنوان گوگل](https://developers.google.com/search/docs/appearance/title-link)

برآوردهای استعلامی تأمین‌کننده با Offer منتشر نمی‌شوند. دادهٔ Product به محصول دارای پیشنهاد خرید معتبر یا امتیاز تأییدشده محدود است. قوانین پیش‌فرض همچنان noindex هستند و تا انتشار نسخهٔ CMS در نقشهٔ سایت نمی‌آیند. [راهنمای Product گوگل](https://developers.google.com/search/docs/appearance/structured-data/product-snippet)

## انتشار محتوا

۱۸ محصول به‌روزرسانی شدند. ۱۶ محصول سه ردیف مشخصات دارند که ارائه‌دهنده، کاربرد و محل مشاهدهٔ شرایط پلن را مشخص می‌کنند. عنوان و توضیحات صفحات اشتراک Claude، Cursor و Grok از صفحهٔ اعتبار API تفکیک شد. عنوان Freepik و Adobe کوتاه‌تر شد. لحن ضمانت ChatGPT یکدست شد و مفاد پوشش همان است. عبارت ثابت ناموجود بودن دو گزینه از توضیح Nord حذف شد تا با تغییر موجودی ناسازگار نشود.

پیش از نوشتن، محتوای زندهٔ هر ۱۸ محصول با نسخهٔ قبلی دادهٔ منبع تطبیق داده شد. ابزار محتوا نقش فعلی مدیر، طرح اعتبارسنجی مشترک API، تاریخ و مقدارهای قبلی را کنترل کرد. مشخصات از قبل واردشده در پنل حفظ می‌شوند. دو فایل بازگشت با مجوز ۰۶۰۰ در دایرکتوری محافظت‌شدهٔ `qa-staging/seo-editorial-20261121` نگه‌داری شدند. اجرای مجدد ۱۸ ردیف یکسان و صفر تغییر گزارش داد.

## بررسی‌ها و حدود

- `npm run verify` با ۱۸۰ بررسی پایه و مجموعهٔ جداگانهٔ محافظت، خرید و تحویل روی پایگاه‌دادهٔ یک‌بارمصرف موفق بود. رگرسیون‌های محتوا انتخاب محصول، حفظ مشخصات موجود، تکرار، تعارض ویرایش و رد نقش غیرمدیر را پوشش دادند.
- ESLint فایل‌های تغییرکرده و بیلد production وب موفق بودند. هر دو اجرای `npm audit` با CA سیستم و اعتبارسنجی TLS فعال، صفر مورد گزارش کردند.
- روی دامنهٔ زنده، تغییر مسیر، حضور فقط یک DeepSeek در فهرست، نقشهٔ سایت، تصویر قوانین، مشخصات ۱۶ محصول و پیوند پشتیبانی برای محصول ناموجود بررسی شدند. همهٔ روابط دوطرفهٔ ۱۰ مقاله با ۸ محصول و ۴ جفت اشتراک/API بررسی شدند. درخواست ناشناس سفارش‌ها، تیکت‌ها و آمار مدیریت ۴۰۱ با هدر private/no-store دریافت کرد.
- سه خطای گزارش‌شدهٔ ۵۰۲ برای n8n، Freepik و Linear در ۲۱ نوامبر ساعت ۱۱:۲۰:۴۰ تا ۱۱:۲۰:۴۱ UTC در لاگ مبدأ تأیید شدند. Nginx در همان بازه خطای اتصال به API ثبت کرده بود. هر سه مسیر پس از آن دوباره ۲۰۰ دادند.
- گزارش ایندکس و CTR در Search Console بررسی نشد.
