# اعلان ثبت‌نام در تلگرام

ثبت‌نام موفق پس از ساخت حساب یک اعلان برای چت خصوصی مدیر می‌فرستد. پیام فقط شناسهٔ کوتاه عضو را دارد. اعتبارسنجی، دسترسی حساب و هدر خصوصی no-store همان مسیر ثبت‌نام هستند. خطای ارسال، ثبت‌نام را خراب نمی‌کند. ارسال از همان سازوکار اعلان ربات استفاده می‌کند و صف جدا ندارد.

رگرسیون ساختگی ابتدا نبود اعلان را بازتولید کرد. پس از تغییر، پیام به مدیر تعیین‌شده رفت. ثبت تکراری و ورودی نامعتبر اعلان ندادند و ایمیل یا رمز در پیام نبود. verify کامل با دیتابیس یک‌بارمصرف، lint فایل‌های تغییرکرده، ساخت تصویر تولید API و هر دو بررسی وابستگی موفق بودند. هر دو audit صفر هشدار دادند.

نسخهٔ API روی سایت نصب شد. محیط اجرایی مقادیر موجود ربات و چت مدیر را از پیکربندی خصوصی بازیابی کرد. Telegram با دو درخواست فقط‌خواندنی هویت ربات و نوع خصوصی چت مقصد را تأیید کرد. سلامت دیتابیس، پاسخ ۴۰۰ ثبت‌نام نامعتبر روی HTTPS و فعال‌بودن تایمرهای بکاپ و Blu مشاهده شدند. حساب آزمایشی در دیتابیس اصلی یا پیام آزمایشی واقعی ساخته نشد. تصویر قبلی برای بازگشت حفظ شد.
