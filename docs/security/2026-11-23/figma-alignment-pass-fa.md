# بازبینی تطابق بخش‌ها با فیگما

بخش‌ها با فریم‌های فایل فیگما مقایسه شدند: صفحهٔ اصلی (D)، حساب کاربری (۰۵)، پنل مدیریت (۰۷، نمای کلی و پوسته)، صفحهٔ ثابت و ۴۰۴ (۰۶) و موبایل صفحهٔ اصلی (۰۸). برای صفحه‌های نیازمند ورود، پیش‌نمایش محلی فقط‌خواندنی حالت اختیاری `--signed-in` و `--admin` گرفت که کاربر، سفارش، پیام، تیکت و آمار نمونه برمی‌گرداند. این حالت فقط درخواست GET دارد، در سرور تولید استفاده نمی‌شود و داده یا حساب واقعی ندارد.

## اصلاح‌ها

- سربرگ در حالت ورود: پیوندهای «حساب من» و «صندوق پیام» از منوی اصلی به نوار ابزار رفتند (آیکن صندوق پیام با تعداد خوانده‌نشده و دکمهٔ «حساب من»). خروج در ستون حساب و منوی موبایل باقی است. مدیر همچنان پیوند «مدیریت» دارد و پیوند صندوق پیام نمی‌بیند.
- قاب حساب: عنوان صفحه بدون کارت، برچسب «حساب اوستا»، حالت فعال نعنایی و نشان تعداد پیام خوانده‌نشده.
- داشبورد: کارت‌های آمار با آیکن و توضیح، جدول سفارش‌ها با ستون‌های شماره، اقلام و تاریخ، وضعیت، مبلغ و دکمهٔ «مشاهده» یا «تکمیل پرداخت»؛ در موبایل هر سفارش کارت جداست.
- جزئیات سفارش: نشان وضعیت کنار عنوان، روش پرداخت در خط زیر عنوان، کارت «پرداخت و رسیدها» با وضعیت، روش و کد پیگیری (فقط برای سفارش پرداخت‌شدهٔ همان کاربر؛ پاسخ API همچنان `private, no-store`). فیلد اطلاعات تحویل دکمه‌های آیکنی نمایش و کپی با برچسب دسترس‌پذیر گرفت.
- صندوق پیام: یک کارت با ردیف‌های آیکن‌دار، نقطهٔ خوانده‌نشده و زمان در کنار.
- امنیت حساب: تغییر رمز و ایمیل بازیابی کنار هم؛ هشدار «با تغییر رمز، همهٔ دستگاه‌های دیگر خارج می‌شوند» اضافه شد و با کد API (افزایش نسخهٔ نشست و لغو نشست‌ها) تطبیق داده شد.
- پنل مدیریت: ستون کناری با هویت مدیر، آیکن هر بخش، نشان تعداد سفارش تأمین‌کننده و «بازگشت به فروشگاه»؛ در دسکتاپ نوار بالایی حذف و در موبایل حفظ شد. نمای کلی: تاریخ امروز، دکمهٔ صف رسیدها، نوار پرفروش‌ترین‌ها و رنگ موجودی کم.
- صفحهٔ اصلی: حداکثر ۸ دسته (دو ردیف کامل) و حذف فاصلهٔ اضافی بالای فوتر.
- صفحه‌های ثابت: نوار عنوان با مسیر صفحه و تاریخ به‌روزرسانی و فهرست بخش‌ها از سرتیترهای `##`.

## بررسی‌ها

- `npm run verify` (شامل `test:isolated` با دیتابیس یک‌بارمصرف)، `npm run lint`، بیلد تولید API و وب و هر دو `npm audit` با ۰ آسیب‌پذیری پاس شدند.
- `admin-workspace-contracts` پیش از این تغییر هم شکست می‌خورد (ماک آن مسیر صف تأمین‌کننده را پاسخ نمی‌دهد) و جزو `verify` نیست.

## محدودیت‌ها

- سیزده صفحهٔ داخلی دیگر پنل مدیریت فقط از نظر پوسته بررسی شدند، نه محتوای هر صفحه.
- میز کارت‌به‌کارت و صفحهٔ گفت‌وگوی تیکت فقط با دادهٔ نمونه یا بدون دادهٔ کارت دیده شدند.
- برچسب پلن‌هایی مثل «CHATGPT PRO» از دادهٔ محصول است و با CSS تغییر نکرد.
- این تغییرات هنوز منتشر نشده‌اند. فضای آزاد دیسک سرور حدود ۷۱۰ مگابایت است و برای ساخت ایمیج تازهٔ وب احتمالاً کافی نیست.
