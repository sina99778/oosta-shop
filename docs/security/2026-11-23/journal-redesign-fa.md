# بازطراحی مجله و صفحهٔ مقاله مطابق فیگما

- فهرست مجله: نوار سرمه‌ای تمام‌عرض با برچسب‌های موضوعی، کارت برگزیده با دکمهٔ «ادامه مطلب» و کارت‌های گرد. مقاله‌های بدون تصویر جلد به‌جای کادر خالی، جلد رنگی با برچسب موضوع می‌گیرند. عنوان‌های «تازه‌ترین مقاله» و «آرشیو» برای صفحه‌خوان‌ها حفظ شدند.
- صفحهٔ مقاله: مسیر صفحه، نویسنده و زمان مطالعه، جلد تمام‌عرض، ستون چسبان «در این مقاله»، «ابزارهای این مقاله» با قیمت شروع و دکمه‌های اشتراک، کادر مشاوره در تلگرام و مقاله‌های مرتبط.
- فهرست مطالب از بخش‌های `##` همان متن ساخته می‌شود و شناسه‌ها (`section-1`، ...) هم در فهرست و هم روی سرتیترها از یک قاعده می‌آیند. در پیش‌نمایش ویرایشگر شناسه ساخته نمی‌شود.
- قیمت شروع فقط از پلن‌های قیمت‌دار، موجود و بدون استعلام همان پاسخ عمومی `/products/:slug` گرفته می‌شود. داده یا مسیر API تازه‌ای اضافه نشد.
- اشتراک‌گذاری فقط با اقدام خواننده انجام می‌شود: پیوند `t.me/share` و کپی آدرس عمومی مقاله. هیچ داده‌ای خودکار ارسال نمی‌شود.
- آزمون‌ها: قراردادهای مجله و SEO (اکنون با نمایش واقعی مقاله و پیوند محصول در ستون کناری)، `test:isolated` با دیتابیس یک‌بارمصرف، لینت، بیلد تولید API و وب و هر دو `npm audit` با ۰ آسیب‌پذیری پاس شدند.
- در یک اجرا، آزمون «Failing lookups must not starve later paid orders» در `supplier-fulfillment-regressions` شکست خورد. همان مجموعه سه بار جداگانه و یک بار در اجرای کامل دوباره پاس شد. این تغییر کد API را عوض نکرده است. احتمال وابستگی این آزمون به زمان/ترتیب سفارش‌ها باز است و هنوز بررسی نشده.
- در پیش‌نمایش محلی با داده و مقالهٔ نمونهٔ فقط‌خواندنی، عرض ۱۴۴۰ و ۳۷۵ پیکسل و حالت تیره بدون سرریز افقی بررسی شد.
