سه ابزار Cursor، Claude Code و GitHub Copilot هر سه کمکتان می‌کنند سریع‌تر کد بنویسید، اما سه فلسفهٔ متفاوت دارند:

- **Cursor:** یک ویرایشگر کامل است.
- **Claude Code:** یک دستیار است که در ترمینال و ویرایشگرهای مختلف کار می‌کند.
- **Copilot:** افزونه‌ای است که به ویرایشگر فعلی‌تان اضافه می‌شود.

انتخاب درست بیشتر به روش کار شما بستگی دارد تا به «بهترین مدل».

قیمت‌های این مقاله از صفحه‌های رسمی، در آبان ۱۴۰۵ و به دلار بدون مالیات است.

## Cursor: ساختار قیمت جدید

Cursor قیمت‌گذاری‌اش را عوض کرده است. بسیاری از منابع فارسی هنوز پلن قدیمی ۲۰ دلاری Pro را ذکر می‌کنند، در حالی که صفحهٔ رسمی فعلی این پلن‌ها را نشان می‌دهد:

- **Free:** رایگان، با مصرف محدود.
- **Plus:** ۸ دلار در ماه. طبق صفحهٔ رسمی، در این پلن «فقط مدل‌های Grok در دسترس‌اند».
- **Premium:** ۳۰ دلار در ماه، چهار برابر مصرف Plus، به‌علاوهٔ ایجنت‌های ابری، بازبینی کد و دسترسی به مدل‌های شرکت‌های دیگر.
- **Super:** ۱۰۰ دلار در ماه، ۱۵ برابر مصرف Plus.
- **Ultra:** ۲۰۰ دلار در ماه، ۵۰ برابر مصرف Plus.

**نکتهٔ مهم:** مدل‌های شرکت‌های دیگر (مثل Claude و GPT) از پلن Premium به بالا در دسترس‌اند، اما جدا و بر اساس مصرف، با قیمت فهرست API حساب می‌شوند. اگر عادت دارید داخل Cursor با Claude کار کنید، هزینه‌اش از سهمیهٔ اشتراک جداست. سهمیهٔ اشتراک هر هفته تازه می‌شود.

## Claude Code: دستیار ترمینال و ویرایشگر

Claude Code ابزار کدنویسی Anthropic است و در این محیط‌ها کار می‌کند:

- ترمینال روی ویندوز، مک و لینوکس
- افزونهٔ VS Code (که در Cursor هم نصب می‌شود)
- افزونهٔ IDEهای JetBrains مثل IntelliJ، PyCharm و WebStorm
- اپلیکیشن دسکتاپ
- نسخهٔ وب در claude.ai/code

پلن Pro (۲۰ دلار در ماه، یا ۱۷ دلار با پرداخت سالانه) شامل Claude Code است. پلن‌های بالاتر سهمیهٔ بیشتری دارند:

- **Max** (۱۰۰ دلار): پنج برابر مصرف Pro
- **Ultra** (۲۰۰ دلار): ده برابر مصرف هفتگی Pro

**نقطهٔ قوت:** کار روی پروژه‌های چندفایلی، فهم ساختار کل کدبیس و انجام کارهای چندمرحله‌ای، مثل بازنویسی یک ماژول یا پیدا کردن علت یک باگ پیچیده.

**هزینهٔ پنهان:** سهمیه در بازه‌های پنج‌ساعته و هفتگی حساب می‌شود و مصرف آن به طول گفت‌وگو بستگی دارد. یک نشست خیلی طولانی که کل تاریخچه را با خود می‌کشد، سهمیه را خیلی سریع‌تر از چند نشست کوتاه و متمرکز تمام می‌کند.

## GitHub Copilot: ارزان‌ترین شروع

Copilot حالا مصرف را با «اعتبار هوش مصنوعی» دلاری حساب می‌کند. هر اعتبار یک سنت است.

- **Free:** رایگان، ۲۰۰۰ تکمیل کد در ماه و دسترسی به مدل‌های پایه.
- **Pro:** ۱۰ دلار در ماه، تکمیل کد نامحدود و ۱۵ دلار اعتبار ماهانه.
- **Pro+:** ۳۹ دلار در ماه و ۷۰ دلار اعتبار ماهانه، با مدل‌های سنگین‌تر از جمله Opus.
- **Max:** ۱۰۰ دلار در ماه و ۲۰۰ دلار اعتبار ماهانه.

تکمیل کد از اعتبار کم نمی‌کند، اما حالت ایجنت، چت و بازبینی کد از اعتبار مصرف می‌کنند. مقدار مصرف به مدل انتخابی بستگی دارد. Copilot مدل‌های Claude، GPT، Gemini و Grok را در یک‌جا ارائه می‌دهد.

**ایجنت‌های دیگر داخل Copilot:** صفحهٔ رسمی می‌گوید می‌توانید کار را به ایجنت‌های Claude Code و Codex بسپارید. این قابلیت در Pro+ و Max قطعاً هست، اما صفحهٔ قیمت دربارهٔ پلن Pro تناقض دارد.

**دانشجوها:** دانشجویان تأییدشده در GitHub Education به پلن Copilot Student دسترسی دارند. شرایط تأیید را در صفحهٔ [GitHub Education](/fa/products/github-education) ببینید.

## کدام را انتخاب کنم؟

- **می‌خواهید ارزان شروع کنید و ویرایشگرتان را عوض نکنید:** Copilot Pro با ۱۰ دلار.
- **روی پروژه‌های بزرگ کار می‌کنید و کار چندمرحله‌ای می‌خواهید:** Claude Code با Claude Pro. اگر زیاد کار می‌کنید، Max.
- **یک ویرایشگر کامل با هوش مصنوعی یکپارچه می‌خواهید:** Cursor. ولی حساب کنید آیا مدل‌های Grok برایتان کافی است یا هزینهٔ جداگانهٔ Claude و GPT را هم باید اضافه کنید.

ترکیب هم رایج است. خیلی‌ها Claude Code را داخل VS Code یا Cursor نصب می‌کنند تا هم ویرایشگر دلخواه را داشته باشند و هم از اشتراک Claude استفاده کنند. در این حالت مصرف از سهمیهٔ اشتراک Claude کم می‌شود، نه از Cursor.

## دو هشدار

1. **حریم خصوصی کد:** در پلن‌های شخصی، تنظیمات پیش‌فرض دربارهٔ استفاده از داده‌ها را بررسی کنید. اگر روی کد محرمانهٔ شرکت کار می‌کنید، پلن‌های تیمی معمولاً تعهد روشن‌تری برای استفاده نکردن از داده در آموزش مدل دارند.
2. **دسترسی از ایران:** این سرویس‌ها مشمول تحریم‌اند و روش تهیهٔ اشتراک روی ریسک حساب اثر دارد. مقالهٔ [اکانت اختصاصی، اشتراکی یا ارتقای حساب شخصی](/fa/blog/dedicated-vs-shared-ai-accounts) را پیش از خرید بخوانید.
