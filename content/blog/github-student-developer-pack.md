**GitHub Student Developer Pack** مجموعه‌ای از ابزارها و اعتبارهای رایگان برای دانشجوهاست که GitHub و شرکت‌های همکارش ارائه می‌دهند. برای دانشجوی برنامه‌نویسی، ارزش آن می‌تواند به صدها دلار در سال برسد.

اطلاعات این مقاله از صفحه‌های رسمی GitHub Education در آبان ۱۴۰۵ است.

## چه چیزهایی در بسته هست؟

فهرست پیشنهادها مرتب عوض می‌شود. نمونه‌های شناخته‌شده:

- **GitHub Copilot** برای دانشجویان تأییدشده (پلن Copilot Student)
- **GitHub Codespaces** و **GitHub Pro** در دورهٔ دانشجویی
- **دامنه و SSL:** طبق صفحهٔ رسمی، Namecheap یک سال دامنهٔ `.me` و یک سال گواهی SSL رایگان می‌دهد. Name.com هم دامنهٔ رایگان با پسوندهای منتخب دارد.
- **اعتبار ابری:** از جمله Microsoft Azure
- **ابزارهای آموزشی و توسعه:** مثل DataCamp و IDEهای JetBrains

مدت و شرایط هر پیشنهاد را خود شرکت همکار تعیین می‌کند. بیشترشان از لحظهٔ فعال‌سازی شروع می‌شوند. فهرست به‌روز را در [صفحهٔ رسمی بسته](https://education.github.com/pack) ببینید.

## چه کسی واجد شرایط است؟

طبق مستندات GitHub:

- باید در یک **برنامهٔ تحصیلی مدرک‌دار** ثبت‌نام کرده باشید: دبیرستان، کالج، دانشگاه یا آموزش در خانه.
- دست‌کم **۱۳ سال** سن داشته باشید.
- یک **حساب شخصی GitHub** داشته باشید.
- **مدرک دانشجویی** ارائه کنید: کارت دانشجویی با تاریخ معتبر، برنامهٔ کلاسی، کارنامه یا نامهٔ تأیید اشتغال به تحصیل.

اگر دانشگاهتان ایمیل دانشگاهی می‌دهد، ممکن است لازم باشد آن را پیش از درخواست به حساب GitHub اضافه و تأیید کنید.

## دلایل رایج رد شدن درخواست

مستندات GitHub این موارد را نام می‌برد:

- **مدرک ناخوانا یا نامعتبر:** عکس تار است، یا تاریخ مدرک وضعیت فعلی تحصیل را نشان نمی‌دهد.
- **ایمیل دانشگاهی تأییدنشده:** ایمیل دانشگاهی در حساب تأیید نشده، یا دامنه‌اش شناخته‌شده نیست.
- **ایمیل تکراری:** ایمیل دانشگاهی قبلاً برای حساب دیگری استفاده شده است. داشتن چند حساب شخصی طبق قوانین GitHub مجاز نیست.
- **وضعیت تحصیلی:** دوره‌های آموزشی غیررسمی بدون مدرک مورد قبول نیستند.

اگر رد شدید، مدرک واضح‌تر بفرستید و دوباره درخواست بدهید. بعد از پایان دسترسی هم، اگر هنوز دانشجو هستید، می‌توانید دوباره درخواست کنید. بعضی پیشنهادهای شرکت‌های همکار تمدیدشدنی نیستند.

## وضعیت کاربران ایران

GitHub در صفحهٔ «GitHub and trade controls» دو نکتهٔ مهم گفته است:

- GitHub مجوز OFAC دارد که خدماتش را به توسعه‌دهندگان ساکن ایران ارائه دهد. طبق همین صفحه، مجوز شامل همهٔ خدمات عمومی و خصوصی، رایگان و پولی است.
- اما همین صفحه دربارهٔ **Copilot** جداگانه می‌گوید که فروش یا صادرات آن به مقصدهای تحریمی بدون مجوز ممکن نیست و ایران را در فهرست این مقصدها نام می‌برد.

یعنی دسترسی به خود GitHub از ایران مجاز است، اما **وضعیت Copilot برای کاربران ایران روشن نیست**. GitHub همچنین می‌گوید پرداخت‌کننده‌های شخص ثالث ممکن است پرداخت از ایران را مسدود کنند. موقعیت کاربر از منابعی مثل IP و سابقهٔ پرداخت تشخیص داده می‌شود.

درخواست صادقانه با مدرک واقعی بدهید. ارائهٔ مدرک یا موقعیت نادرست خلاف قوانین GitHub است و حساب را به خطر می‌اندازد.

## اگر واجد شرایط نیستید

برای Copilot پلن رایگان (۲۰۰۰ تکمیل کد در ماه) هم هست. پلن Pro با ۱۰ دلار در ماه شروع می‌شود. مقایسهٔ ابزارهای کدنویسی را در مقالهٔ [Cursor، Claude Code یا Copilot](/fa/blog/cursor-vs-claude-code-vs-copilot) ببینید.

اوستا [GitHub Education](/fa/products/github-education) و [GitHub Copilot](/fa/products/copilot) را هم ارائه می‌دهد. شرایط هر گزینه در صفحهٔ محصول آمده است.
