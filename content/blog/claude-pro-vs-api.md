برای استفاده از Claude دو راه دارید: **اشتراک** (Pro، Max یا Ultra) با هزینهٔ ثابت ماهانه، یا **اعتبار API** که بر اساس مصرف پرداخت می‌شود. کدام بصرفه‌تر است به این بستگی دارد که با Claude چه کار می‌کنید.

قیمت‌ها از صفحه‌های رسمی Anthropic در آبان ۱۴۰۵ و به دلار و بدون مالیات‌اند.

## اشتراک: هزینهٔ ثابت، سهمیهٔ محدود

- **Pro:** ۲۰ دلار در ماه، یا ۱۷ دلار با پرداخت سالانه. شامل Opus، Sonnet و Haiku، اعتبار مصرفی برای Fable و دسترسی به Claude Code.
- **Max:** ۱۰۰ دلار. پنج برابر مصرف Pro و ۱۰۰ دلار اعتبار ماهانهٔ API.
- **Ultra:** ۲۰۰ دلار. ده برابر مصرف هفتگی Pro و ۲۰۰ دلار اعتبار API.

اشتراک سهمیهٔ پنج‌ساعته و هفتگی دارد. هزینه ثابت است، ولی اگر سهمیه تمام شود باید صبر کنید. اشتراک رابط‌های آمادهٔ Claude را هم در اختیارتان می‌گذارد: وب، اپ موبایل، Claude Code و قابلیت تحقیق.

## API: پرداخت به‌ازای هر توکن

در API برای هر **میلیون توکن** ورودی و خروجی جداگانه پرداخت می‌کنید:

- **Opus 5.5:** ۴ دلار ورودی و ۲۰ دلار خروجی
- **Sonnet 5.5:** ۲ دلار ورودی و ۱۰ دلار خروجی
- **Haiku 5.5:** ۰٫۱۰ دلار ورودی و ۰٫۵۰ دلار خروجی، برای پرامپت تا ۱۰۰ هزار توکن
- **Fable 5.2:** ۸ دلار ورودی و ۴۰ دلار خروجی

دو راه برای کم کردن هزینه:

- **Batch API:** برای کارهایی که فوری نیستند، ۵۰ درصد تخفیف دارد.
- **کش پرامپت (Prompt caching):** خواندن بخش تکراری پرامپت از کش، در Opus 5.5 و Sonnet 5.5 فقط ۵ درصد قیمت عادی ورودی است.

یک نکته: طبق مستندات Anthropic، مدل‌های جدید از نسخهٔ ۴٫۷ به بعد توکنایزر تازه‌ای دارند که برای همان متن حدود ۳۰ درصد توکن بیشتری می‌سازد. در برآورد هزینه این را حساب کنید.

## چند مثال هزینه

این مثال‌ها تقریبی‌اند و برای مقایسه آمده‌اند. هزینهٔ واقعی به طول پیام‌ها بستگی دارد.

- **گفت‌وگوی روزمره با Sonnet 5.5:** اگر روزی ۳۰ پیام بفرستید و هر پیام با تاریخچه حدود ۵ هزار توکن ورودی و ۵۰۰ توکن خروجی داشته باشد، ماهانه حدود ۴٫۵ میلیون توکن ورودی و ۴۵۰ هزار توکن خروجی می‌شود. یعنی حدود **۱۴ دلار**، کمتر از Pro.
- **کار سنگین با اسناد بلند و Opus:** چند PDF صدصفحه‌ای در روز به‌سرعت ده‌ها میلیون توکن ورودی می‌شود. هزینهٔ API از Pro بیشتر می‌شود و اشتراک بصرفه‌تر است.
- **پردازش انبوه متن با Haiku:** مثل دسته‌بندی هزاران پیام مشتری. API خیلی ارزان است و اشتراک اصلاً برای این کار ساخته نشده.

## کدام را انتخاب کنم؟

**اشتراک بهتر است اگر:**

- با رابط Claude (وب، اپ، Claude Code) کار می‌کنید و برنامه‌نویسی با API نمی‌کنید.
- هر روز و زیاد کار می‌کنید و نمی‌خواهید هزینه‌تان متغیر باشد.
- به Claude Code برای برنامه‌نویسی نیاز دارید.

**API بهتر است اگر:**

- می‌خواهید Claude را داخل برنامه، ربات یا ابزار خودتان استفاده کنید.
- مصرفتان کم و نامنظم است.
- کار انبوه و خودکار دارید، به‌خصوص با Haiku یا Batch.

**ترکیب هر دو:** پلن‌های Max و Ultra اعتبار ماهانهٔ API هم دارند. اگر هم رابط Claude را می‌خواهید و هم API، این پلن‌ها هر دو را یک‌جا می‌دهند.

برای مقایسهٔ ابزارهای کدنویسی، مقالهٔ [Cursor، Claude Code یا Copilot](/fa/blog/cursor-vs-claude-code-vs-copilot) را ببینید.

## یک هشدار

کلید API را مثل رمز عبور نگه دارید. کلید لورفته یعنی هر کسی می‌تواند به حساب شما خرج کند. در کنسول Anthropic سقف هزینه تعیین کنید. اشتراک‌گذاری کلید API با دیگران هم طبق شرایط Anthropic ممنوع است. ریسک‌های روش تهیه را در مقالهٔ [اکانت اختصاصی، اشتراکی یا ارتقای حساب شخصی](/fa/blog/dedicated-vs-shared-ai-accounts) بخوانید.
